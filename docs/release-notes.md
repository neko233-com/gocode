gocode v0.16.0 adds native right/down editor groups. Ctrl/Cmd+\ splits right, Shift adds a downward split, and Ctrl/Cmd+1..8 focuses groups. Native 4-DIP sashes resize the layout. Each group has independent tabs, caret, selection and scroll while sharing one canonical document, undo history, save points and LSP/VSIX lifecycle.

Closing a shared view preserves dirty text and its services. Close group confirms only dirty resources unique to that group; Save waits for actual disk acknowledgement. Captured toolbar actions reject changed or expired groups, and background opens retain their originating group without stealing newer focus. UTF-16 caret transforms preserve Chinese/emoji and multiline CRLF edits across views.

Huge-file views share one bounded file-backed index with independent page requests and cancellation. The reader remains alive after the original view closes and is released with the last document view. Native acceptance streams actual files, renders first/tail pages in separate viewports, closes the original and reads again, then verifies the whole-file SHA256. Windows 2025 adds an actual 1 GiB split; Windows console/GUI and Mac Intel/ARM normal/1.5/2 gates accompany existing race, VSIX, recovered LSP, search/history, highlighted terminal and installer regressions. Publication requires successful exact-source CI and reuses its tested packages.

The split tree allows at most eight groups. Full group persistence, tab move/drop/docking, multi-window and VSIX visibleTextEditors/viewColumn remain unfinished. Large files stay read-only. Complete IME/grapheme/bidi/multicursor/accessibility, SCM/DAP and full VS Code/GPUI/official Copilot VSIX parity remain open. Copilot follows the accepted official SDK/Language Server route while VSIX compatibility expands. Exact source, release, package and installed evidence belongs in agent docs/status.md.
