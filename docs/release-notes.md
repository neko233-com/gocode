gocode v0.17.0 connects real VSIX TextEditor objects to native editor groups using public godesktop v0.10.0. One canonical TextDocument is shared by distinct visible views; hidden tabs stay out of visibleTextEditors. View identity survives column renumbering, while disposed views and reopened documents reject stale operations. The tree supports nine groups and Ctrl/Cmd+1..9.

workspace.openTextDocument loads an eligible document on the bounded worker without focusing or showing a tab. showTextDocument supports Active/Beside/One–Nine, preserveFocus and UTF-16 selection. A causal receipt keeps delayed opens from stealing newer focus. Selection, reveal and edits run in order, validate view/document/version, and publish native visibility, column, range, selection and focus events. Independent manual/reveal scrolling persists until caret movement resumes. Actual Document.save still waits for disk acknowledgement.

The new native -groups-vsix-smoke installs a real temporary VSIX, verifies hidden/shared views, Unicode/CRLF edit and independent reveal, uses actual mouse focus/close, checks surviving/disposed references, and verifies saved bytes. Windows console/GUI and Mac Intel/ARM normal/1.5/2 gates join the existing editor, recovered LSP, history/search, highlighted terminal, actual GiB split and installer regressions. Publication requires successful exact-source CI and reuses its tested packages.

Short position queries and bounded line previews no longer copy whole multi-megabyte lines. Optional Node hosts use owned source/config files instead of Windows command-line-sized payloads, with bounded requests and exit cleanup. Native service admission rejects files over 2 MiB before whole-file reads. Huge-file browsing remains bounded and read-only.

Full tabGroups, preview/pin/docking/persistence, editor options/decorations/snippets/undo merging, multi-window, complete IME/grapheme/bidi/multicursor/accessibility, SCM/DAP and full VS Code/GPUI/official Copilot VSIX parity remain open. Copilot follows the accepted official SDK/Language Server route while VSIX compatibility expands. Exact source, release, package and installed evidence belongs in agent docs/status.md.
