gocode v0.13.0 replaces filename filtering with native workspace content search. The 26-pixel input and 22-pixel grouped result rows follow current VS Code stable 1.140.0 / main 8ce9c47. Search supports Unicode case folding, whole words, Go regex, include/exclude globs and nested Git ignore rules. Immutable open-editor snapshots supersede disk; input stays native Go/godesktop.

One cancellable worker and one latest queued request stream across unlimited line lengths. Query changes debounce and invalidate old receipts. Literal matches use bounded chunks; regex literal prefixes scan candidates before anchored verification. Results retain byte/UTF-16 coordinates and content digests. Navigation rechecks actual content, document instance/version, focus and generation; stale results cannot move the newer caret or write source. Large results open the file-backed byte viewport at their actual offset.

Standard regex/Git oracles, Unicode/chunk/CRLF tests, fuzz regressions and held-receipt worker tests accompany native console/GUI gates. Actual single-line GiB search and native tail navigation verify bounded allocation and unchanged source hashes. Mac Intel/ARM also capture completed search pixels at normal/1.5/2 density; all readback is process-owned.

The app continues using public godesktop v0.7.0. Existing native tabs, VSIX edits, file reload/conflicts, recovered LSP, highlighted ConPTY/PTY and free MSI/ZIP/Mac/update channels remain covered. Copilot follows the accepted official SDK/Language Server route; no paid prompt is needed for ordinary CI.

This remains an engineering preview. Full VS Code/GPUI parity, PCRE2 lookaround/backreferences, workspace replace, complete ignore/encoding/provider integration, SCM/DAP and advanced editing/extension capabilities remain unfinished. Exact-source CI, publication and installed evidence are recorded in agent docs/status.md as verified.
