# gocode v0.24.0 Windows candidate

This release consolidates Windows workbench improvements and real Go/TypeScript
language support. The UI remains native Go with Direct3D12/DirectWrite, consuming
the independently published godesktop v0.17.0. Releases are built and tested
locally, then uploaded against immutable tags; push/PR Actions are disabled.

- Native File/submenus, Quick Input and confirmation dialogs use source-measured
  rounded shadows with actual body/ancestor clipping and pointer behavior.
- Extension details retain their header while scrolling real wrapped metadata;
  exact-ID catalog queries and native enable/disable/uninstall controls are kept.
- Install Go or TypeScript language support from the command palette or
  `-install-language-extension go|typescript`. Original pinned VSIX packages use
  native LSP adapters for completion, diagnostics, formatting, hover and definition.
  Repeated installation verifies existing files. Disabled/uninstalled adapters
  release their owned server trees and cannot reappear through implicit fallback.
- Language processes have bounded Windows Job ownership, actual shutdown
  acknowledgement and independently restarted sessions. Recovery replays unsaved
  content and rejects old-session results. Language names appear correctly in
  the status bar, including TypeScript/JavaScript React.
- Keyboard preset persistence checks actual writer completion; built-in VS Code
  and JetBrains presets remain available. Large-file navigation acceptance reports
  real current-request failures and preserves existing work/verification deadlines.

Windows amd64 MSI and ZIP are the current packaging target. Go uses golang.Go
0.50.0 with gopls v0.23.0; TypeScript uses
vscode.typescript-language-features1.95.3/tsserver5.6.3 with
typescript-language-server6.0.1. TypeScript and optional extension/AI services
require Node.js24. Latest Go VSIX0.56.1 exceeds the current public framework's
manifest bound; explicit versioned native installation does not silently substitute
another version for a catalog request.

Original language-extension JS activation, debugger/testing APIs, complete VSIX
compatibility and full VS Code parity remain outside the implemented adapter
scope. Open VSX is the default extension catalog; a separately authorized Gallery
endpoint can be configured. macOS stays on the previously released v0.23.0
assets/channels; this Windows candidate does not relabel old Mac binaries.

Local source-specific native popup, real Go/TypeScript recovery/pixels and actual
GiB checks are recorded in the engineering ledger. Source f4a also passes five
complete local Prepare checks and35 actual ZIP native gates. MSI's prior-install
step exposes an owner command-line parser failure; the corrected MSI-only owner
now passes the actual original-package full lifecycle in a space/Chinese root. Final
corrected-source/package validation, exact MSI lifecycle, existing-publisher-key
signature and genuine signed prior rollback must pass before publication. This
file is reviewable candidate notes, not evidence that the release is public.
